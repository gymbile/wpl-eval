# results/ — the frozen v0.6 corpus

560 committed trial artifacts (`<model>[+tag]__<scenario>__<lane>__<phase>.json`)
covering three sub-corpora: v0.5 OpenAI long-plan, v0.6 Anthropic long-plan,
v0.6 short-plan. Single-turn + multi-turn, Lane A (raw LLM) and Lane B
(LLM + WPL).

Each file contains the full audit trail: verbatim model output
(`raw_text` / `raw_texts_per_turn`), extractor output, extracted plans,
violations, tokens, latency, cost. Every number in `docs/V0_6_RESULTS.md`
re-derives from these files **without API calls** — see "Reproducing
without re-spending" in the repo README.

**Frozen.** Do not add, regenerate, or rescore in place; these back the
published v0.6 numbers (tag `v0.6.0`). New sweeps go in their own
versioned directory (see `../results-v0.7/`). The `results-table.md`,
`summary.md`, `results.csv` here are generated by `tsx src/report.ts`.
